INTERSTELLAR DOCKING — ACTUALIZACIÓN CPU v3

OBJETIVOS DE ESTA ACTUALIZACIÓN
- Orientación inicial: Lander nivelado, con su eje longitudinal hacia el Endurance.
- Cada toque de izquierda/derecha cambia la velocidad exactamente -1/+1 RPM.
- Mantener la tecla cambia la velocidad a -3/+3 RPM por segundo.
- Se conserva la velocidad de inicio actual del Lander: 0 RPM.
- La ventana de acoplamiento muestra velocidad relativa; cuando el Lander iguala los -68 RPM del Endurance, el monitor muestra 0.0 RPM.
- El indicador SPEED muestra porcentaje de sincronización.

MODELO RELATIVO DEL MONITOR
    relative_monitor_rpm = (lander_rpm - ENDURANCE_RPM) * (15.0 / 68.0)
Como ENDURANCE_RPM = -68.0:
    Lander = 0 RPM    -> monitor = +15.0 RPM, sincronización 0%
    Lander = -34 RPM  -> monitor = +7.5 RPM, sincronización 50%
    Lander = -68 RPM  -> monitor = 0.0 RPM, sincronización 100%

CONTROLES
- A / Flecha izquierda: toque -1 RPM; mantener -3 RPM/s.
- D / Flecha derecha: toque +1 RPM; mantener +3 RPM/s.
- W / Flecha arriba: subir.
- S / Flecha abajo: bajar.
- E: activar/desactivar aproximación.
- C: cambiar modo de cámara.
- R: reiniciar.
- Esc: salir.

# INTERSTELLAR // Docking CPU Edition — update 3

Renderizador 3D por software en CPU. La escena, la cámara y el monitor de primera persona se rasterizan en framebuffers en memoria; `minifb` solo presenta el búfer de color.

## Cambios de esta actualización

- El Lander inicia con roll cero y con su eje longitudinal local `+Z` apuntando hacia el eje de acoplamiento mundial `+X` del Endurance. Esto lo deja nivelado y con el morro hacia el puerto desde el primer fotograma.
- Se conserva la velocidad inicial del Lander de la versión anterior: `0 RPM`.
- Una pulsación nueva de A/Flecha izquierda resta exactamente `1 RPM`; una pulsación nueva de D/Flecha derecha suma exactamente `1 RPM`.
- Si se mantiene una de esas teclas, la velocidad continúa cambiando a `3 RPM/s`, más lentamente que los pasos discretos. Al soltar, el valor se mantiene; no hay retorno automático.
- La miniventana muestra velocidad angular relativa al Endurance. El objetivo relativo es `0.0 RPM`, porque desde el módulo de acoplamiento no hay giro diferencial cuando ambos giran igual.
- El monitor escala la diferencia real de velocidad a una escala de `15 RPM`: `relative = (lander_rpm - (-68)) * 15 / 68`. Por eso, con Lander a `0 RPM` muestra `+15 RPM`; con Lander a `-68 RPM` muestra `0 RPM`.
- `SPEED` indica el porcentaje de sincronización de velocidad: `0%` al inicio con Lander a `0 RPM`, `100%` al igualar `-68 RPM`.
- El dial del monitor usa un objetivo estacionario a cero; la aguja naranja solo deriva cuando hay velocidad angular relativa.
- Se añadieron pruebas unitarias para el giro por toque, el giro al mantener, la orientación inicial y la velocidad relativa cero.

#[derive(Clone, Copy, Debug)]
struct Vertex {
    position: Vec3,
    normal: Vec3,
}

#[derive(Clone, Copy, Debug)]
struct Triangle {
    a: Vertex,
    b: Vertex,
    c: Vertex,
    color: Vec3,
}

#[derive(Clone, Debug, Default)]
struct CpuModel {
    triangles: Vec<Triangle>,
}

fn load_gltf_model(path: &Path) -> Result<CpuModel, Box<dyn Error>> {
    let (document, buffers, _images) = gltf::import(path)?;
    let mut model = CpuModel::default();
    let scene = document
        .default_scene()
        .or_else(|| document.scenes().next())
        .ok_or_else(|| format!("{} no contiene una escena glTF", path.display()))?;

    for node in scene.nodes() {
        collect_node(node, Mat4::IDENTITY, &buffers, &mut model)?;
    }
    if model.triangles.is_empty() {
        return Err(format!("{} no contiene primitivas triangulares", path.display()).into());
    }
    Ok(model)
}

fn collect_node(
    node: gltf::Node<'_>,
    parent_transform: Mat4,
    buffers: &[gltf::buffer::Data],
    output: &mut CpuModel,
) -> Result<(), Box<dyn Error>> {
    let local = Mat4::from_cols_array_2d(&node.transform().matrix());
    let world = parent_transform * local;

    if let Some(mesh) = node.mesh() {
        for primitive in mesh.primitives() {
            if primitive.mode() != gltf::mesh::Mode::Triangles {
                continue;
            }
            let reader = primitive.reader(|buffer| Some(&buffers[buffer.index()]));
            let Some(position_reader) = reader.read_positions() else {
                continue;
            };
            let positions: Vec<Vec3> = position_reader.map(Vec3::from_array).collect();
            if positions.len() < 3 {
                continue;
            }
            let normals: Vec<Vec3> = reader
                .read_normals()
                .map(|values| values.map(Vec3::from_array).collect())
                .unwrap_or_default();
            let indices: Vec<u32> = reader
                .read_indices()
                .map(|values| values.into_u32().collect())
                .unwrap_or_else(|| (0..positions.len() as u32).collect());

            let material = primitive.material();
            let pbr = material.pbr_metallic_roughness();
            let factor = pbr.base_color_factor();
            let mat_name = material.name().unwrap_or("").to_ascii_lowercase();
            let color = if mat_name.contains("glass") {
                Vec3::new(0.22, 0.55, 0.72)
            } else {
                Vec3::new(
                    factor[0].max(0.36),
                    factor[1].max(0.38),
                    factor[2].max(0.42),
                )
            };

            let transformed_positions: Vec<Vec3> = positions
                .iter()
                .map(|p| world.transform_point3(*p))
                .collect();
            let transformed_normals: Vec<Vec3> = normals
                .iter()
                .map(|n| world.transform_vector3(*n).normalize_or_zero())
                .collect();

            for indices3 in indices.chunks_exact(3) {
                let ia = indices3[0] as usize;
                let ib = indices3[1] as usize;
                let ic = indices3[2] as usize;
                if ia >= positions.len() || ib >= positions.len() || ic >= positions.len() {
                    continue;
                }
                let pa = transformed_positions[ia];
                let pb = transformed_positions[ib];
                let pc = transformed_positions[ic];
                let face_normal = (pb - pa).cross(pc - pa).normalize_or_zero();
                let na = transformed_normals.get(ia).copied().unwrap_or(face_normal);
                let nb = transformed_normals.get(ib).copied().unwrap_or(face_normal);
                let nc = transformed_normals.get(ic).copied().unwrap_or(face_normal);
                output.triangles.push(Triangle {
                    a: Vertex { position: pa, normal: if na.length_squared() < 0.1 { face_normal } else { na } },
                    b: Vertex { position: pb, normal: if nb.length_squared() < 0.1 { face_normal } else { nb } },
                    c: Vertex { position: pc, normal: if nc.length_squared() < 0.1 { face_normal } else { nc } },
                    color,
                });
            }
        }
    }

    for child in node.children() {
        collect_node(child, world, buffers, output)?;
    }
    Ok(())
}

}

#[derive(Debug)]
struct GameState {
    elapsed: f32,
    endurance_angle: f32,
    lander_angle: f32,
    lander_rpm: f32,
    altitude: f32,
    distance: f32,
    approach_enabled: bool,
    vertical_speed: f32,
    relative_x_speed: f32,
    lateral_offset: f32,
    lateral_speed: f32,
    phase: GamePhase,
    camera_mode: CameraMode,
    orbit_angle: f64,
    gravity_m_s2: f64,
}

impl Default for GameState {
    fn default() -> Self {
        Self {
            elapsed: 0.0,
            endurance_angle: 0.0,
            // Zero roll at spawn: the Lander's longitudinal axis starts level
            // and points directly toward the Endurance docking port.
            lander_angle: 0.0,
            // Preserve the starting angular speed from the previous build.
            lander_rpm: 0.0,
            altitude: 2.0,
            distance: 22.0,
            approach_enabled: false,
            vertical_speed: 0.0,
            relative_x_speed: 0.0,
            lateral_offset: 0.0,
            lateral_speed: 0.0,
            phase: GamePhase::Active,
            camera_mode: CameraMode::Automatic,
            orbit_angle: 0.0,
            gravity_m_s2: EARTH_MU / ORBIT_RADIUS_M.powi(2),
        }
    }
}

impl GameState {
    fn lander_position(&self) -> Vec3 {
        Vec3::new(
            TARGET_PORT_X - self.distance - LANDER_NOSE_OFFSET,
            self.altitude,
            self.lateral_offset,
        )
    }

    fn phase_error_rad(&self) -> f32 {
        wrap_angle(self.lander_angle - self.endurance_angle)
    }

    fn rpm_error(&self) -> f32 {
        (self.lander_rpm - ENDURANCE_RPM).abs()
    }

    /// Angular velocity seen from the docking module, scaled to a +/-15 RPM
    /// instrument. Equal Lander/Endurance rotation therefore reads exactly 0.
    fn relative_monitor_rpm(&self) -> f32 {
        (self.lander_rpm - ENDURANCE_RPM)
            * (MONITOR_RANGE_RPM / ENDURANCE_RPM.abs())
    }

    /// 100% means the Lander has the same angular velocity as the Endurance.
    fn speed_sync_percent(&self) -> f32 {
        (100.0 * (1.0 - self.rpm_error() / ENDURANCE_RPM.abs())).clamp(0.0, 100.0)
    }

    fn alignment_percent(&self) -> f32 {
        let speed_score = self.speed_sync_percent() / 100.0;
        let phase_score =
            (1.0 - self.phase_error_rad().abs() / 18.0_f32.to_radians()).clamp(0.0, 1.0);
        let height_score = (1.0 - self.altitude.abs() / 1.25).clamp(0.0, 1.0);
        (100.0 * (0.50 * speed_score + 0.35 * phase_score + 0.15 * height_score))
            .clamp(0.0, 100.0)
    }

    fn hard_lock(&self) -> bool {
        self.rpm_error() <= 0.8
            && self.phase_error_rad().abs() <= 2.0_f32.to_radians()
            && self.altitude.abs() <= 0.20
            && self.lateral_offset.abs() <= 0.20
    }

    fn can_approach(&self) -> bool {
        self.alignment_percent() >= 84.0
            && self.rpm_error() <= 3.5
            && self.phase_error_rad().abs() <= 8.0_f32.to_radians()
            && self.altitude.abs() <= 0.65
            && self.lateral_offset.abs() <= 0.55
    }

    fn status(&self) -> &'static str {
        match self.phase {
            GamePhase::Docked => "DOCKING COMPLETE",
            GamePhase::Collision => "HULL CONTACT / ABORT",
            GamePhase::Active if self.approach_enabled && self.can_approach() => "FINAL APPROACH",
            GamePhase::Active if self.approach_enabled => "HOLD / ALIGNMENT REQUIRED",
            GamePhase::Active if self.hard_lock() => "TARGET LOCKED",
            GamePhase::Active => "TARGET UNLOCKED",
        }
    }

    fn orbital_mean_motion(&self) -> f64 {
        (EARTH_MU / ORBIT_RADIUS_M.powi(3)).sqrt()
    }

    fn orbital_speed_km_s(&self) -> f64 {
        (EARTH_MU / ORBIT_RADIUS_M).sqrt() / 1000.0
    }

    fn orbital_period_min(&self) -> f64 {
        TAU as f64 / self.orbital_mean_motion() / 60.0
    }
}

#[derive(Clone, Copy, Default)]
struct InputState {
    left: bool,
    right: bool,
    left_pressed: bool,
    right_pressed: bool,
    up: bool,
    down: bool,
    approach: bool,
    reset: bool,
    camera: bool,
}

fn update_simulation(game: &mut GameState, input: InputState, dt: f32) {
    if input.reset {
        *game = GameState::default();
        return;
    }
    if input.camera {
        game.camera_mode = match game.camera_mode {
            CameraMode::Automatic => CameraMode::Wide,
            CameraMode::Wide => CameraMode::Chase,
            CameraMode::Chase => CameraMode::Docking,
            CameraMode::Docking => CameraMode::Automatic,
        };
    }
    if input.approach && game.phase == GamePhase::Active {
        game.approach_enabled = !game.approach_enabled;
    }

    let dt64 = dt as f64;
    let mean_motion = game.orbital_mean_motion();
    game.orbit_angle = (game.orbit_angle + mean_motion * dt64).rem_euclid(TAU as f64);
    game.elapsed += dt;
    game.endurance_angle = wrap_angle(
        game.endurance_angle + ENDURANCE_RPM * TAU / 60.0 * dt,
    );

    if game.phase == GamePhase::Docked {
        game.lander_rpm = ENDURANCE_RPM;
        game.lander_angle = wrap_angle(game.lander_angle + ENDURANCE_RPM * TAU / 60.0 * dt);
        game.altitude = 0.0;
        game.distance = 0.0;
        game.relative_x_speed = 0.0;
        return;
    }
    if game.phase == GamePhase::Collision {
        game.approach_enabled = false;
        return;
    }

    // Each discrete key-down changes angular speed by exactly 1 RPM.
    // Holding a key after the first frame continues changing speed slowly
    // (3 RPM per second), so a tap is precise and a hold is convenient.
    let tap_delta = (input.right_pressed as i32 - input.left_pressed as i32) as f32;
    game.lander_rpm += tap_delta;

    // Do not add the hold ramp during the initial key-down frame; that frame
    // has already applied the discrete +/-1 RPM tap above.
    if !input.left_pressed && !input.right_pressed {
        let hold_direction = (input.right as i32 - input.left as i32) as f32;
        game.lander_rpm += hold_direction * ROTATION_HOLD_RATE_RPM_S * dt;
    }
    game.lander_rpm = game.lander_rpm.clamp(-MAX_LANDER_RPM, MAX_LANDER_RPM);
    game.lander_angle = wrap_angle(game.lander_angle + game.lander_rpm * TAU / 60.0 * dt);

    // Dinámica orbital relativa (ecuaciones de Hill-Clohessy-Wiltshire).
    // x: eje radial de aproximación; y: desviación vertical; z: fuera del plano.
    let n = mean_motion as f32;
    let x_from_station_center = game.distance + 10.8;
    let orbital_ax = 3.0 * n * n * x_from_station_center + 2.0 * n * game.vertical_speed;
    let orbital_ay = -2.0 * n * game.relative_x_speed;
    let orbital_az = -n * n * game.lateral_offset;

    let vertical_input = (input.up as i32 - input.down as i32) as f32;
    let vertical_thruster = vertical_input * 3.2;
    let vertical_damping = -1.15 * game.vertical_speed - 0.65 * game.altitude;
    let lateral_damping = -1.25 * game.lateral_speed - 0.7 * game.lateral_offset;
    game.vertical_speed += (vertical_thruster + vertical_damping + orbital_ay) * dt;
    game.altitude += game.vertical_speed * dt;
    game.lateral_speed += (lateral_damping + orbital_az) * dt;
    game.lateral_offset += game.lateral_speed * dt;
    game.altitude = game.altitude.clamp(-5.0, 5.0);
    game.lateral_offset = game.lateral_offset.clamp(-4.0, 4.0);

    // Control PD de velocidad de cierre. Se inhibe si no hay un bloqueo seguro.
    let target_closing_speed = if game.approach_enabled && game.can_approach() {
        -APPROACH_SPEED
    } else {
        0.0
    };
    let approach_accel = (target_closing_speed - game.relative_x_speed) * 1.8;
    let x_accel = orbital_ax + approach_accel;
    game.relative_x_speed += x_accel * dt;
    game.relative_x_speed = game.relative_x_speed.clamp(-1.0, 0.8);
    game.distance += game.relative_x_speed * dt;

    // Volumen de colisión del aro frontal y del cuello de acoplamiento.
    if game.distance < 1.35
        && (game.altitude.abs() > 0.95 || game.lateral_offset.abs() > 0.85)
    {
        game.phase = GamePhase::Collision;
        game.approach_enabled = false;
    } else if game.distance <= 0.035 {
        game.distance = 0.0;
        game.approach_enabled = false;
        if game.hard_lock() && game.relative_x_speed.abs() <= 0.9 {
            game.phase = GamePhase::Docked;
            game.lander_rpm = ENDURANCE_RPM;
            game.vertical_speed = 0.0;
            game.relative_x_speed = 0.0;
        } else {
            game.phase = GamePhase::Collision;
        }
    }
}

#[derive(Clone, Copy)]
struct Camera {
    position: Vec3,
    target: Vec3,
    fov_y: f32,
    near: f32,
}

impl Default for Camera {
    fn default() -> Self {
        Self {
            // Side-on profile: the Lander's docking axis (+X) projects horizontally.
            position: Vec3::new(20.0, 18.0, 78.0),
            target: Vec3::new(-5.0, 0.0, 0.0),
            fov_y: 48.0_f32.to_radians(),
            near: 0.08,
        }
    }
}

impl Camera {
    fn basis(&self) -> (Vec3, Vec3, Vec3) {
        let forward = (self.target - self.position).normalize_or_zero();
        let right = forward.cross(Vec3::Y).normalize_or_zero();
        let up = right.cross(forward).normalize_or_zero();
        (forward, right, up)
    }

    fn project(&self, point: Vec3, width: usize, height: usize) -> Option<ScreenVertex> {
        let (forward, right, up) = self.basis();
        let relative = point - self.position;
        let z = relative.dot(forward);
        if z <= self.near || !z.is_finite() {
            return None;
        }
        let focal = (height as f32 * 0.5) / (self.fov_y * 0.5).tan();
        Some(ScreenVertex {
            x: width as f32 * 0.5 + relative.dot(right) * focal / z,
            y: height as f32 * 0.5 - relative.dot(up) * focal / z,
            z,
        })
    }
}

#[derive(Clone, Copy)]
struct ScreenVertex {
    x: f32,
    y: f32,
    z: f32,
}

fn automatic_camera_shot(elapsed: f32) -> usize {
    ((elapsed / CAMERA_SHOT_SECONDS).floor() as usize) % CAMERA_SHOT_COUNT
}

fn camera_shot_name(game: &GameState) -> &'static str {
    match game.camera_mode {
        CameraMode::Wide => "EXTERIOR PROFILE",
        CameraMode::Chase => "LANDER FOLLOW",
        CameraMode::Docking => "DOCKING CLOSE",
        CameraMode::Automatic => match automatic_camera_shot(game.elapsed) {
            0 => "EXTERIOR PROFILE",
            1 => "LOW ORBIT PASS",
            2 => "WIDE REVEAL",
            3 => "UNDERFRAME",
            4 => "LANDER TRACK",
            5 => "SIDE DOCKING",
            6 => "PORT APPROACH",
            _ => "RETURN WIDE",
        },
    }
}

fn update_camera(camera: &mut Camera, game: &GameState, dt: f32) {
    let lander = game.lander_position();
    let port = Vec3::new(TARGET_PORT_X, 0.0, 0.0);
    let shot = automatic_camera_shot(game.elapsed);
    let (desired_position, look_target) = match game.camera_mode {
        CameraMode::Wide => (
            Vec3::new(20.0, 18.0, 78.0),
            Vec3::new(-5.0, 0.0, 0.0),
        ),
        CameraMode::Chase => (
            lander + Vec3::new(-12.0, 9.0, 38.0),
            port,
        ),
        CameraMode::Docking => (
            lander + Vec3::new(-7.0, 4.5, 28.0),
            port,
        ),
        CameraMode::Automatic => match shot {
            // These exterior views all look across the station's X axis so the
            // Endurance and the Lander read horizontally instead of end-on.
            0 => (Vec3::new(20.0, 18.0, 78.0), Vec3::new(-5.0, 0.0, 0.0)),
            1 => (Vec3::new(5.0, -17.0, -72.0), Vec3::new(-4.0, 0.0, 0.0)),
            2 => (Vec3::new(24.0, 28.0, 94.0), Vec3::new(-4.0, 0.0, 0.0)),
            3 => (Vec3::new(-20.0, -19.0, -64.0), Vec3::new(-4.0, 0.0, 0.0)),
            4 => (lander + Vec3::new(-12.0, 8.0, 38.0), port),
            5 => (lander + Vec3::new(-8.0, 5.0, 31.0), port),
            6 => (lander + Vec3::new(-5.0, 2.0, 26.0), port),
            _ => (Vec3::new(13.0, 22.0, 82.0), Vec3::new(-4.0, 0.0, 0.0)),
        },
    };
    // Smooth cinematic camera cuts; the shot itself advances automatically every 7 seconds.
    let blend = 1.0 - (-3.0 * dt).exp();
    camera.position = camera.position.lerp(desired_position, blend);
    camera.target = camera.target.lerp(look_target, blend);
}

struct Framebuffer {
    width: usize,
    height: usize,
    color: Vec<u32>,
    depth: Vec<f32>,
}

impl Framebuffer {
    fn new(width: usize, height: usize) -> Self {
        Self {
            width,
            height,
            color: vec![0; width * height],
            depth: vec![f32::INFINITY; width * height],
        }
    }

    fn clear(&mut self, color: u32) {
        self.color.fill(color);
        self.depth.fill(f32::INFINITY);
    }

    fn pixel(&mut self, x: i32, y: i32, color: u32) {
        if x >= 0 && y >= 0 && (x as usize) < self.width && (y as usize) < self.height {
            let index = y as usize * self.width + x as usize;
            self.color[index] = color;
        }
    }

    fn fill_rect(&mut self, x: i32, y: i32, width: i32, height: i32, color: u32) {
        let x0 = x.max(0);
        let y0 = y.max(0);
        let x1 = (x + width).min(self.width as i32);
        let y1 = (y + height).min(self.height as i32);
        for py in y0..y1 {
            let start = py as usize * self.width + x0 as usize;
            let end = py as usize * self.width + x1 as usize;
            self.color[start..end].fill(color);
        }
    }

    fn blit(&mut self, source: &Framebuffer, destination_x: i32, destination_y: i32) {
        for source_y in 0..source.height {
            let target_y = destination_y + source_y as i32;
            if target_y < 0 || target_y >= self.height as i32 {
                continue;
            }
            let source_start = source_y * source.width;
            let target_x0 = destination_x.max(0);
            let target_x1 = (destination_x + source.width as i32).min(self.width as i32);
            if target_x0 >= target_x1 {
                continue;
            }
            let skip = (target_x0 - destination_x) as usize;
            let count = (target_x1 - target_x0) as usize;
            let target_start = target_y as usize * self.width + target_x0 as usize;
            self.color[target_start..target_start + count]
                .copy_from_slice(&source.color[source_start + skip..source_start + skip + count]);
        }
    }

    fn rect(&mut self, x: i32, y: i32, width: i32, height: i32, color: u32) {
        self.line(x, y, x + width, y, color);
        self.line(x, y + height, x + width, y + height, color);
        self.line(x, y, x, y + height, color);
        self.line(x + width, y, x + width, y + height, color);
    }

    fn line(&mut self, mut x0: i32, mut y0: i32, x1: i32, y1: i32, color: u32) {
        let dx = (x1 - x0).abs();
        let sx = if x0 < x1 { 1 } else { -1 };
        let dy = -(y1 - y0).abs();
        let sy = if y0 < y1 { 1 } else { -1 };
        let mut error = dx + dy;
        loop {
            self.pixel(x0, y0, color);
            if x0 == x1 && y0 == y1 {
                break;
            }
            let e2 = 2 * error;
            if e2 >= dy {
                error += dy;
                x0 += sx;
            }
            if e2 <= dx {
                error += dx;
                y0 += sy;
            }
        }
    }

    fn circle(&mut self, cx: i32, cy: i32, radius: i32, color: u32) {
        let mut previous: Option<(i32, i32)> = None;
        for i in 0..=96 {
            let a = i as f32 / 96.0 * TAU;
            let p = (
                cx + (a.cos() * radius as f32) as i32,
                cy + (a.sin() * radius as f32) as i32,
            );
            if let Some(last) = previous {
                self.line(last.0, last.1, p.0, p.1, color);
            }
            previous = Some(p);
        }
    }

    fn text(&mut self, x: i32, y: i32, value: &str, color: u32, scale: i32) {
        let mut cursor_x = x;
        let mut cursor_y = y;
        for ch in value.chars() {
            if ch == '\n' {
                cursor_x = x;
                cursor_y += 9 * scale;
                continue;
            }
            let rows = glyph(ch.to_ascii_uppercase());
            for (row_index, row) in rows.iter().enumerate() {
                for col in 0..5 {
                    if *row & (1 << (4 - col)) != 0 {
                        self.fill_rect(
                            cursor_x + col * scale,
                            cursor_y + row_index as i32 * scale,
                            scale,
                            scale,
                            color,
                        );
                    }
                }
            }
            cursor_x += 6 * scale;
        }
    }

    fn raster_triangle(
        &mut self,
        a: ScreenVertex,
        b: ScreenVertex,
        c: ScreenVertex,
        ca: Vec3,
        cb: Vec3,
        cc: Vec3,
    ) {
        let min_x = a.x.min(b.x).min(c.x).floor().max(0.0) as i32;
        let max_x = a.x.max(b.x).max(c.x).ceil().min(self.width as f32 - 1.0) as i32;
        let min_y = a.y.min(b.y).min(c.y).floor().max(0.0) as i32;
        let max_y = a.y.max(b.y).max(c.y).ceil().min(self.height as f32 - 1.0) as i32;
        if min_x > max_x || min_y > max_y {
            return;
        }
        let area = edge(a.x, a.y, b.x, b.y, c.x, c.y);
        if area.abs() < 0.0001 {
            return;
        }
        for y in min_y..=max_y {
            for x in min_x..=max_x {
                let px = x as f32 + 0.5;
                let py = y as f32 + 0.5;
                let w0 = edge(b.x, b.y, c.x, c.y, px, py) / area;
                let w1 = edge(c.x, c.y, a.x, a.y, px, py) / area;
                let w2 = 1.0 - w0 - w1;
                if w0 < 0.0 || w1 < 0.0 || w2 < 0.0 {
                    continue;
                }
                // Interpolación de profundidad perspectiva-correcta.
                let inv_z = w0 / a.z + w1 / b.z + w2 / c.z;
                if inv_z <= 0.0 {
                    continue;
                }
                let z = 1.0 / inv_z;
                let index = y as usize * self.width + x as usize;
                if z >= self.depth[index] {
                    continue;
                }
                let p0 = (w0 / a.z) / inv_z;
                let p1 = (w1 / b.z) / inv_z;
                let p2 = (w2 / c.z) / inv_z;
                let color = ca * p0 + cb * p1 + cc * p2;
                self.color[index] = pack_rgb(color);
                self.depth[index] = z;
            }
        }
    }
}

fn edge(ax: f32, ay: f32, bx: f32, by: f32, px: f32, py: f32) -> f32 {
    (px - ax) * (by - ay) - (py - ay) * (bx - ax)
}

fn pack_rgb(color: Vec3) -> u32 {
    let c = color.clamp(Vec3::ZERO, Vec3::ONE) * 255.0;
    ((c.x as u32) << 16) | ((c.y as u32) << 8) | c.z as u32
}

fn shade(base: Vec3, normal: Vec3, position: Vec3, camera: &Camera) -> Vec3 {
    let n = normal.normalize_or_zero();
    let sun_dir = Vec3::new(-0.42, 0.74, 0.52).normalize();
    let point_light = Vec3::new(-18.0, 20.0, 28.0);
    let point_dir = (point_light - position).normalize_or_zero();
    let point_distance = point_light.distance_squared(position);
    let view_dir = (camera.position - position).normalize_or_zero();
    let half_vec = (sun_dir + view_dir).normalize_or_zero();
    let diffuse_sun = n.dot(sun_dir).max(0.0);
    let diffuse_point = n.dot(point_dir).max(0.0) * (1.0 / (1.0 + point_distance * 0.0015));
    let specular = n.dot(half_vec).max(0.0).powf(22.0) * 0.20;
    let light = 0.19 + diffuse_sun * 0.62 + diffuse_point * 0.72 + specular;
    (base * light + Vec3::new(0.008, 0.018, 0.028)).clamp(Vec3::ZERO, Vec3::ONE)
}

fn render_model(
    framebuffer: &mut Framebuffer,
    camera: &Camera,
    model: &CpuModel,
    transform: Mat4,
) {
    render_model_lod(framebuffer, camera, model, transform, 1);
}

fn render_model_lod(
    framebuffer: &mut Framebuffer,
    camera: &Camera,
    model: &CpuModel,
    transform: Mat4,
    triangle_stride: usize,
) {
    let stride = triangle_stride.max(1);
    for (triangle_index, triangle) in model.triangles.iter().enumerate() {
        // The miniature first-person viewport uses a CPU-friendly geometry LOD.
        if triangle_index % stride != 0 {
            continue;
        }
        let pa = transform.transform_point3(triangle.a.position);
        let pb = transform.transform_point3(triangle.b.position);
        let pc = transform.transform_point3(triangle.c.position);
        let center = (pa + pb + pc) / 3.0;
        let geometric_normal = (pb - pa).cross(pc - pa).normalize_or_zero();
        if geometric_normal.dot(camera.position - center) <= 0.0 {
            continue;
        }
        let Some(sa) = camera.project(pa, framebuffer.width, framebuffer.height) else { continue; };
        let Some(sb) = camera.project(pb, framebuffer.width, framebuffer.height) else { continue; };
        let Some(sc) = camera.project(pc, framebuffer.width, framebuffer.height) else { continue; };
        if sa.x.max(sb.x).max(sc.x) < 0.0
            || sa.y.max(sb.y).max(sc.y) < 0.0
            || sa.x.min(sb.x).min(sc.x) >= framebuffer.width as f32
            || sa.y.min(sb.y).min(sc.y) >= framebuffer.height as f32
        {
            continue;
        }
        let na = transform.transform_vector3(triangle.a.normal).normalize_or_zero();
        let nb = transform.transform_vector3(triangle.b.normal).normalize_or_zero();
        let nc = transform.transform_vector3(triangle.c.normal).normalize_or_zero();
        let ca = shade(triangle.color, na, pa, camera);
        let cb = shade(triangle.color, nb, pb, camera);
        let cc = shade(triangle.color, nc, pc, camera);
        framebuffer.raster_triangle(sa, sb, sc, ca, cb, cc);
    }
}

/// Converts the GLB's imported forward axis (+Z) into the Endurance docking
/// direction (+X), while keeping the roll around the docking axis itself.
fn lander_docking_rotation(roll_rad: f32) -> Quat {
    let forward_to_port = Quat::from_rotation_y(FRAC_PI_2);
    let roll_about_docking_axis = Quat::from_axis_angle(Vec3::X, roll_rad);
    roll_about_docking_axis * forward_to_port
}

fn render_scene(
    framebuffer: &mut Framebuffer,
    camera: &Camera,
    game: &GameState,
    endurance: &CpuModel,
    lander: &CpuModel,
) {
    let endurance_transform = Mat4::from_rotation_x(game.endurance_angle);
    // The imported GLB's longitudinal axis is +Z. Map +Z to world +X (the
    // Endurance docking axis), then apply roll about that same longitudinal
    // axis. At launch the roll is zero, so the Lander is level and nose-first.
    let lander_rotation = lander_docking_rotation(game.lander_angle);
    let lander_transform = Mat4::from_scale_rotation_translation(
        Vec3::splat(LANDER_SCALE),
        lander_rotation,
        game.lander_position(),
    );
    render_model(framebuffer, camera, endurance, endurance_transform);
    render_model(framebuffer, camera, lander, lander_transform);

    // Retícula de aproximación dibujada también por software.
    let port = Vec3::new(TARGET_PORT_X, 0.0, 0.0);
    for i in -2..=2 {
        let offset = i as f32 * 0.55;
        draw_world_line(framebuffer, camera, port + Vec3::new(0.0, -1.6, offset), port + Vec3::new(0.0, 1.6, offset), 0x1A647D);
        draw_world_line(framebuffer, camera, port + Vec3::new(0.0, offset, -1.6), port + Vec3::new(0.0, offset, 1.6), 0x1A647D);
    }
    draw_world_line(framebuffer, camera, port + Vec3::new(-2.0, 0.0, 0.0), port + Vec3::new(2.0, 0.0, 0.0), 0x39BDE4);
    draw_world_line(framebuffer, camera, port + Vec3::new(0.0, -2.0, 0.0), port + Vec3::new(0.0, 2.0, 0.0), 0x39BDE4);
}

fn render_first_person_view(
    framebuffer: &mut Framebuffer,
    game: &GameState,
    endurance: &CpuModel,
    stars: &[Vec3],
) {
    framebuffer.clear(0x02070C);
    let lander_nose = game.lander_position() + Vec3::X * LANDER_NOSE_OFFSET;
    let camera = Camera {
        position: lander_nose + Vec3::X * 0.18,
        // The camera looks straight along the docking axis. Altitude and lateral
        // errors therefore move the port away from the centre reticle.
        target: lander_nose + Vec3::X * 40.0,
        fov_y: 58.0_f32.to_radians(),
        near: 0.05,
    };
    render_starfield(framebuffer, &camera, stars);
    let endurance_transform = Mat4::from_rotation_x(game.endurance_angle);
    render_model_lod(framebuffer, &camera, endurance, endurance_transform, 4);
    draw_docking_port_overlay(framebuffer, &camera, game);
}

fn draw_docking_port_overlay(framebuffer: &mut Framebuffer, camera: &Camera, game: &GameState) {
    const STEEL: u32 = 0x8299A5;
    const DARK_STEEL: u32 = 0x344D5A;
    const CYAN: u32 = 0x48C9E8;
    const ORANGE: u32 = 0xFFAA62;
    const GREEN: u32 = 0x66E3A5;

    let cx = framebuffer.width as i32 / 2;
    let cy = framebuffer.height as i32 / 2;
    let radius = (framebuffer.height as i32 / 2 - 7).max(30);
    framebuffer.circle(cx, cy, radius, STEEL);
    framebuffer.circle(cx, cy, radius - 5, DARK_STEEL);
    framebuffer.circle(cx, cy, radius - 22, STEEL);
    framebuffer.circle(cx, cy, radius - 27, DARK_STEEL);
    framebuffer.circle(cx, cy, 27, STEEL);
    framebuffer.circle(cx, cy, 21, DARK_STEEL);

    for tick in 0..24 {
        let angle = tick as f32 / 24.0 * TAU;
        let outer = radius - 1;
        let inner = if tick % 3 == 0 { radius - 13 } else { radius - 8 };
        framebuffer.line(
            cx + (angle.cos() * inner as f32) as i32,
            cy + (angle.sin() * inner as f32) as i32,
            cx + (angle.cos() * outer as f32) as i32,
            cy + (angle.sin() * outer as f32) as i32,
            CYAN,
        );
    }

    // Three mechanical locking jaws around the circular hatch.
    let jaw = [
        ((cx - 12, cy - radius + 13), (cx + 12, cy - radius + 13), (cx, cy - radius + 36)),
        ((cx - radius + 13, cy + 13), (cx - radius + 36, cy - 11), (cx - radius + 40, cy + 23)),
        ((cx + radius - 13, cy + 13), (cx + radius - 36, cy - 11), (cx + radius - 40, cy + 23)),
    ];
    for (a, b, c) in jaw {
        framebuffer.line(a.0, a.1, b.0, b.1, STEEL);
        framebuffer.line(b.0, b.1, c.0, c.1, STEEL);
        framebuffer.line(c.0, c.1, a.0, a.1, STEEL);
    }

    let lock_color = if game.can_approach() { GREEN } else { ORANGE };
    let port = Vec3::new(TARGET_PORT_X, 0.0, 0.0);
    if let Some(projected) = camera.project(port, framebuffer.width, framebuffer.height) {
        let tx = projected.x.round() as i32;
        let ty = projected.y.round() as i32;
        framebuffer.circle(tx, ty, 13, lock_color);
        framebuffer.circle(tx, ty, 5, lock_color);
        framebuffer.line(tx - 22, ty, tx + 22, ty, lock_color);
        framebuffer.line(tx, ty - 22, tx, ty + 22, lock_color);
    }

    // Fixed reticle / sight centre.
    framebuffer.circle(cx, cy, 9, CYAN);
    framebuffer.line(cx - 17, cy, cx - 5, cy, CYAN);
    framebuffer.line(cx + 5, cy, cx + 17, cy, CYAN);
    framebuffer.line(cx, cy - 17, cx, cy - 5, CYAN);
    framebuffer.line(cx, cy + 5, cx, cy + 17, CYAN);
}

fn draw_world_line(framebuffer: &mut Framebuffer, camera: &Camera, a: Vec3, b: Vec3, color: u32) {
    if let (Some(pa), Some(pb)) = (
        camera.project(a, framebuffer.width, framebuffer.height),
        camera.project(b, framebuffer.width, framebuffer.height),
    ) {
        framebuffer.line(pa.x as i32, pa.y as i32, pb.x as i32, pb.y as i32, color);
    }
}

fn make_starfield() -> Vec<Vec3> {
    let mut stars = Vec::with_capacity(720);
    let golden_angle = 2.399_963_1_f32;
    for i in 0..720 {
        let fi = i as f32;
        let y = 1.0 - 2.0 * ((fi + 0.5) / 720.0);
        let radius = (1.0 - y * y).sqrt();
        let theta = golden_angle * fi;
        let direction = Vec3::new(radius * theta.cos(), y, radius * theta.sin());
        let shell = 115.0 + ((i * 37) % 95) as f32;
        stars.push(direction * shell);
    }
    stars
}

fn render_starfield(framebuffer: &mut Framebuffer, camera: &Camera, stars: &[Vec3]) {
    for (i, star) in stars.iter().enumerate() {
        if let Some(p) = camera.project(*star, framebuffer.width, framebuffer.height) {
            let brightness = 105 + ((i * 19) % 145) as u32;
            let color = (brightness << 16) | (brightness << 8) | (brightness + 8).min(255);
            framebuffer.pixel(p.x as i32, p.y as i32, color);
            if i % 17 == 0 {
                framebuffer.pixel(p.x as i32 + 1, p.y as i32, color);
            }
        }
    }
}

    for (i, line) in compact_lines.iter().enumerate() {
        let color = if i == 2 {
            if game.alignment_percent() >= 84.0 { GREEN } else { ORANGE }
        } else if i < 2 { CYAN } else { TEXT };
        framebuffer.text(panel_x + 14, panel_y + 49 + i as i32 * 17, line, color, 1);
    }

    if show_more {
        framebuffer.line(panel_x + 12, panel_y + 139, panel_x + panel_width - 12, panel_y + 139, 0x244D61);
        let extras = [
            format!("SPIN ERROR  {:05.2} RPM", game.rpm_error()),
            format!("REL SPIN   {:+05.1} RPM", game.relative_monitor_rpm()),
            format!("SPEED SYNC {:05.1} %", game.speed_sync_percent()),
            format!("PHASE ERR  {:+06.1} DEG", game.phase_error_rad().to_degrees()),
            format!("ALTITUDE   {:+06.2} M", game.altitude),
            format!("LATERAL    {:+06.2} M", game.lateral_offset),
            format!("VERT RATE  {:+05.2} M/S", game.vertical_speed),
            format!("ORBIT ALT   {:04.0} KM", ORBIT_ALTITUDE_M / 1000.0),
            format!("ORBIT SPEED {:04.2} KM/S", game.orbital_speed_km_s()),
            format!("ORBIT PERIOD {:04.1} MIN", game.orbital_period_min()),
            format!("GRAVITY    {:04.2} M/S2", game.gravity_m_s2),
            format!("ORBIT ANG  {:03.0} DEG", game.orbit_angle.to_degrees()),
            format!("FPS        {:04.1}", fps),
            format!("CAMERA     {}", camera_shot_name(game)),
        ];
        for (i, line) in extras.iter().enumerate() {
            framebuffer.text(panel_x + 14, panel_y + 148 + i as i32 * 13, line, TEXT, 1);
        }
    }

    // First-person docking-module inset, based on a separate CPU-rendered camera.
    let dock_x = 16;
    let dock_y = h - 242;
    let dock_width = 500;
    let dock_height = 226;
    framebuffer.fill_rect(dock_x, dock_y, dock_width, dock_height, PANEL);
    framebuffer.rect(dock_x, dock_y, dock_width, dock_height, 0x32647B);
    framebuffer.text(dock_x + 12, dock_y + 11, "DOCKING MODULE // FIRST-PERSON VIEW", CYAN, 1);
    framebuffer.line(dock_x + 10, dock_y + 28, dock_x + dock_width - 10, dock_y + 28, 0x244D61);
    let image_x = dock_x + 10;
    let image_y = dock_y + 36;
    framebuffer.blit(first_person, image_x, image_y);
    framebuffer.rect(image_x, image_y, MINI_WIDTH as i32, MINI_HEIGHT as i32, 0x4B8296);

    let side_x = image_x + MINI_WIDTH as i32 + 12;
    framebuffer.text(side_x, dock_y + 42, "DOCKING DATA", CYAN, 1);
    framebuffer.text(side_x, dock_y + 62, "TARGET  +00.0 RPM", TEXT, 1);
    let relative_monitor_rpm = game.relative_monitor_rpm();
    framebuffer.text(side_x, dock_y + 79, &format!("REL VEL {:+05.1} RPM", relative_monitor_rpm), ORANGE, 1);
    framebuffer.text(side_x, dock_y + 96, &format!("SPEED {:05.1} %", game.speed_sync_percent()), if game.speed_sync_percent() >= 84.0 { GREEN } else { ORANGE }, 1);
    framebuffer.text(side_x, dock_y + 113, &format!("PHASE {:+05.1} DEG", game.phase_error_rad().to_degrees() * (MONITOR_RANGE_RPM / ENDURANCE_RPM.abs())), TEXT, 1);
    framebuffer.text(side_x, dock_y + 130, &format!("ALIGN {:04.1} %", game.alignment_percent()), if game.alignment_percent() >= 84.0 { GREEN } else { ORANGE }, 1);
    framebuffer.fill_rect(side_x, dock_y + 146, 158, 7, 0x122B39);
    framebuffer.fill_rect(side_x, dock_y + 146, (158.0 * game.alignment_percent() / 100.0) as i32, 7, if game.alignment_percent() >= 84.0 { GREEN } else { ORANGE });

    // Relative-rate dial: target remains at zero. The orange needle only moves
    // when the Lander rotates differently from the Endurance.
    let dial_cx = side_x + 78;
    let dial_cy = dock_y + 190;
    framebuffer.circle(dial_cx, dial_cy, 29, 0x2C8DA8);
    framebuffer.circle(dial_cx, dial_cy, 21, 0x1B536A);
    let target_angle = -FRAC_PI_2;
    let player_angle = target_angle
        + game.phase_error_rad() * (MONITOR_RANGE_RPM / ENDURANCE_RPM.abs());
    draw_dial_needle(framebuffer, dial_cx, dial_cy, 25, target_angle, CYAN, 1);
    draw_dial_needle(framebuffer, dial_cx, dial_cy, 17, player_angle, ORANGE, 1);
    framebuffer.circle(dial_cx, dial_cy, 3, TEXT);

    let status_color = match game.phase {
        GamePhase::Docked => GREEN,
        GamePhase::Collision => 0xFF6565,
        GamePhase::Active if game.can_approach() => GREEN,
        _ => ORANGE,
    };
    framebuffer.fill_rect(w - 382, h - 48, 364, 30, PANEL);
    framebuffer.rect(w - 382, h - 48, 364, 30, status_color);
    framebuffer.text(w - 370, h - 39, game.status(), status_color, 1);
}

fn draw_dial_needle(framebuffer: &mut Framebuffer, cx: i32, cy: i32, radius: i32, angle: f32, color: u32, thickness: i32) {
    let x = cx + (angle.cos() * radius as f32) as i32;
    let y = cy + (angle.sin() * radius as f32) as i32;
    framebuffer.line(cx, cy, x, y, color);
    for dx in -thickness..=thickness {
        for dy in -thickness..=thickness {
            if dx * dx + dy * dy <= thickness * thickness {
                framebuffer.pixel(x + dx, y + dy, color);
            }
        }
    }
}
